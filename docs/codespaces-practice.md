## Initial Observations

**What felt straightforward?**

Creating and editing files was fairly straightforward. The interface was similar to other code editors like GEE and R, and running the Python script from the terminal was simple.

**What felt unfamiliar?**

The Git workflow was less familiar, particularly staging changes and committing them. I also had to figure out how to enter a commit message when Git opened a separate editor.

**Where is the Source Control panel located?**

The Source Control panel is located in the left sidebar of Codespaces.

## Understanding Git Workflow

Codespaces is where I can create, edit, and test files before sharing changes. The remote repository on GitHub stores the project's version and commit history. Changes made in Codespaces need to be committed and synced before they appear in the remote repository.
